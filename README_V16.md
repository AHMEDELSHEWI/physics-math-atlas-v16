# أطلس المحاكاة · V16 المجمّع

هذه الحزمة تضم ملف HTML واحدًا يعمل مباشرة، مع 101 تجربة قابلة للتحكم، و14 تجربة فراغية ثلاثية الأبعاد، ومحرر دوال آمن للتفاضل والتكامل، ومعادلات تفاضلية جزئية، وتحويل وحدات، وتصدير واستيراد JSON.

## التشغيل

- افتح `index.html` مباشرة لنسخة Canvas الأساسية.
- لتفعيل التثبيت دون اتصال وService Worker شغّل خادمًا محليًا من هذا المجلد، مثل `python3 -m http.server 8000`، ثم افتح `http://localhost:8000`.
- اسحب داخل مشاهد 3D لتدوير الكاميرا، واستخدم التكبير وإعادة زاوية العرض.

النماذج تعليمية محددة الافتراضات؛ لا تدّعي احتواء كل البراهين أو كل نتائج البحث العلمي.
